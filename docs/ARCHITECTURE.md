# 架构与职责边界

## 调用链

```text
CLI / 第三方 import
  → RecruitmentClient
  → AccountRepository.use（真实账号锁）
  → Platform.withSession（连接与身份校验）
  → Discovery / OutreachService
  → 平台 capability handler
  → 原生页面 / 平台接口
```

`core` 只定义领域类型、能力和平台契约；`runtime` 管账号、存储、锁和浏览器生命周期；`services` 管通用筛选与联系计划。它们都不导入具体平台实现。`src/index.ts` 和 `src/cli/program.ts` 是组合入口，`src/platform/builtins.ts` 组装内置平台。

CLI 命令树通过 `createRecruitProgram` 创建，不使用进程全局可变单例。命令语法从 Commander 生成，能力 schema 从 Zod 生成。平台专用参数放在 `options`，由平台 schema 解析，不扩散到通用命令 flags。

## 账号与身份

账号绑定键由 `[platformId, accountId]` 计算。别名只负责查找该绑定，不拥有登录会话或锁。每次重新登录建立新会话目录，验证身份、关闭浏览器后再替换绑定；其他账号不能覆盖已有别名。

BOSS 首先等待扫码后进入的应用路由，再调用用户信息接口：`/web/geek/` 对应求职端，`/web/chat/` 对应招聘端。不能从登陆页确认身份时直接报错，不猜角色。联系人操作前再次验证账号；发送前验证目标卡片和当前岗位。计划绑定创建时的角色，不能跨角色执行。

公司官网是公开只读会话，无登录凭证，只支持 seeker 角色。链接与跳转必须在该站点声明的 origin 范围内。

## 筛选

`Selection` 是通用输入：关键词、城市、活跃时间上限、数量、页数和平台选项。`Target` 是通用输出：稳定 ID、职位或候选人类型、摘要、活跃度、沟通状态、URL，以及由平台负责的上下文。

活跃度用一个可确认的分钟上限表达，`null` 表示没有证据。BOSS 文本转分钟的逻辑在 BOSS 适配器内。通用服务只比较数字；缺失活跃度时读取详情，仍未知就排除。`any` 显式取消活跃度限制。最多扫描指定页数，按已扫描范围内的活跃程度排序；不宣称全站排序。

## 发送与恢复

计划是不可变的筛选快照。发送记录是是否允许调用远端写操作的唯一依据，历史展示从发送记录读取。相同账号、角色和目标 ID 共用记录；招聘端目标 ID 包含岗位 ID 和候选人 ID。

```text
未记录 → prepare / 重新验证 → pending → sent
                              ↘ indeterminate
```

预检查跳过不占用永久发送记录，后续新计划可重新考虑。只要进入发送阶段，超时、异常和进程中断都不自动重放。`pending` 在下次执行时转成 `indeterminate`。同一批次遇到结果不明时停止新发送，返回 `attention`。`plan run` 可以继续其他未执行条目，结果不明条目始终不会重发。

`contact.send` 不开放给 client 的通用 `invoke` 或 CLI 的 `platform exec`，必须通过计划执行。适配器底层会话接口是扩展协议，直接使用它的集成方需要自行承担编排职责。

BOSS 点击页面原生按钮；回执观察器只接受当前目标匹配的原生沟通接口响应，依据业务状态码确认。不会以“查看简历”“弹出窗口”或“按钮已点击”冒充发送成功。观察器的事件监听和定时器在成功与失败时均清理。

## 扩展

新增招聘平台时，在 `src/platform/<id>/` 放置认证、协议、页面选择器和适配器。通过 `definePlatform` 注册能力，内置平台只在 `builtins.ts` 组合。第三方业务可以通过 `createRecruitmentClient({ platforms })` 注入自己的平台，不需要改 CLI 或筛选服务。

公开官网可以先用配置适配；需要专用登录或投递协议时建立独立平台。没有沟通或投递能力的平台不注册对应写能力。首版没有实现任何公司官网表单自动投递。

## 验证边界

Zod 校验用户参数、配置文件和持久化文件。已建立的内部 TypeScript 契约和平台成功响应直接使用；HTTP、业务错误码与协议可空数据在平台边界处理。不重试未知异常，不重放任何写请求。

CI 包含格式、类型、工作流测试、离线浏览器测试、命令发现与 npm 包导入检查。所有测试数据都是虚构的，浏览器夹具拦截全部请求。真实登录、实时页面与话术效果需要独立验收。
